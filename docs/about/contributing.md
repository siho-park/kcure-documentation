# Contributing

Contributions from researchers who have used the data are what make this site useful. A correction to a single code, or a note that two official pages disagree, saves the next user the same afternoon of detective work.

## Suggesting a correction

The simplest way to suggest a change is an email to [sihopark@kdischool.ac.kr](mailto:sihopark@kdischool.ac.kr?subject=K-CURE%20Data%20Documentation). Please include the link to the page, the change you propose, and its source if there is one, such as a manual, a published paper, or your own experience with the data.

## Using GitHub

Contributors who use GitHub can also suggest a change there directly.

- **Open an issue.** Describe the problem or the missing information in a [GitHub issue](https://github.com/siho-park/kcure-documentation/issues).
- **Edit the page.** Every page has an edit button at the top right that opens its source file on GitHub, where you can propose the change as a pull request.

## Writing a post

Researchers who have worked with the data are welcome to write a post for [Research notes](../blog/index.md). A post can be short and cover a single pitfall, a way of constructing a variable, or a lesson from the application or export process. Send the draft by email to [sihopark@kdischool.ac.kr](mailto:sihopark@kdischool.ac.kr?subject=K-CURE%20Data%20Documentation%20post) in any format, such as Word, Google Docs, or plain text, together with your name and affiliation as they should appear on the post. The draft is then formatted for the site and published under your name.

## What not to post

Never post individual-level records, screenshots of the analysis environment, or statistics computed from the data that have not passed export review (반출심사). Describing the structure of a variable, its codes, and its pitfalls is fine. Numbers from the data should be limited to results that have already been cleared for release, such as published tables.

## Variable pages

The [Variables](../variables/index.md) pages are generated from data dictionary version 4.0 (자료설명서) and the portal's data catalogs. A correction to a variable page is best sent with the page and line of the dictionary or catalog that supports it.
