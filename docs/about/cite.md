# How to cite

If this site helped your research, please cite it as follows.

> Park, Siho. *K-CURE Data Documentation*. https://siho-park.github.io/kcure-documentation/. Accessed [date].

For the Cancer Public Library, also cite the data resource profile, which describes the first release:

> Choi DW, Guk MY, Kim HR, Ryu KS, Kong HJ, Cha HS, Kim HJ, Chae H, Jeon YS, Kim H, Jung J, Im JS, Choi KS. Data Resource Profile: The Cancer Public Library Database in South Korea. *Cancer Research and Treatment*. 2024;56(4):1014-1026. https://doi.org/10.4143/crt.2024.207

Later releases cover more years than that profile. The version actually used should be named from the data dictionary supplied with the extract. The [sources and versions](../datasets/sources.md) page lists the public descriptions of those later releases.
