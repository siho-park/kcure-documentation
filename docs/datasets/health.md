# Health and medical data (보건의료 데이터)

The portal's fourth data menu is not a cancer database. It points at two public-data services run for the Ministry of Health and Welfare.

??? info "Source"
    This page follows the portal's [health-data overview](https://k-cure.mohw.go.kr/portal/dit/phw/inf/viewPhwInf.do) and the home-page count of nine institutions, viewed on 29 October 2026.

- **Open health data.** Files, images, and video that the Ministry publishes for reuse. These are posted objects, not a person-level research extract, so they have no variable list on this site unless a particular file turns out to be one.
- **Health and medical big data (보건의료 빅데이터).** Person-level linkage of data from nine institutions, released to researchers for public-purpose studies. That linkage does need a variable list. It is the platform's own documentation, not the Cancer Public Library dictionary. The safe-use center FAQ also points approved users to the [Health and Medical Big Data Platform](https://hcdl.mohw.go.kr) for reservations.

The nine institutions are not named on the overview page this summary follows. A cancer study does not receive the registry by applying here. Registry studies use the [Cancer Public Library](public-library/index.md). This menu matters when a project needs a public file the cancer library does not carry, or when the work is approved on the big-data platform and then booked into a center that also serves K-CURE.
