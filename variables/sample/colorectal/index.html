    Colorectal sample¶

    대장암 표본. 16 tables, 543 variables in the portal catalog.

    This is a site sample (표본). It is its own database: one cancer site, with the tables listed below. The staging sample of the same site, where the catalog has one, is a separate database. How the two differ is on the sample page.

    The registration table keeps summary stage (SEER_GRP) and the histology code MCODE. Death, eligibility, claims, and the checkup use the same kind of row as the customized library, with fewer columns. There is no COVID-19 table. A screening table appears here only for a site the catalog includes, and only for this site. The checkup and screening year files in this catalog run through 2023.

    Year of birth is not a variable. AGE is age at diagnosis.

    On the code sheet, recorded validity runs from 2007 through 2023.

    The catalog does not list SN_KEY. Claim lines list MID.
